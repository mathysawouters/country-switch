# My shopping rules (Country Switch)

Rule 1 (home country): I live in Belgium. My delivery country is BE.
Rule 2 (shipping): Only buy from a shop that ships to Belgium. If a shop does not deliver to Belgium, refuse it, even when it is the cheapest.
Rule 3 (same item): Only switch shops when it is exactly the same item: same manufacturer SKU, single item, not a bundle or a pack with extra cables.
Rule 4 (minimum saving): Only switch country when I save at least 5 euro compared to the shop I was looking at.
Rule 5 (currency): Only buy in euro.
Rule 6 (authority): The agent may fill a cart by itself. I pay myself. The agent never pays.
